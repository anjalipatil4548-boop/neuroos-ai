# NeuroOS AI — Intelligent Operating System Web Demo

> **Live Website:** [https://neuroos-ai.pages.dev/](https://neuroos-ai.pages.dev/)

**NeuroOS AI** is an interactive web showcase and desktop simulator for a custom operating system built with an embedded AI assistant, task scheduler visualizer, kernel overview, and live command shell.

## Key Features
- **Interactive OS Interface & Shell:** Explore built-in OS workflows, command prompts, and system diagnostics directly in the browser.
- **Ultra-Lightweight Zero-Dependency Build:** Single-page static architecture (~17 KB core HTML) engineered for instant loading anywhere.
- **Systems Architecture Showcase:** Highlights kernel design, process scheduling, and AI-assisted system utilities.
- **Related Source Project:** Based on [`anjalipatil4548-boop/Neuroos-site`](https://github.com/anjalipatil4548-boop/Neuroos-site).

## Tech Stack
- Vanilla HTML5, CSS3 & Zero-Dependency JavaScript
- Deployed globally on **Cloudflare Pages**

## Local Preview
Open `index.html` directly or serve via HTTP:
```bash
npx serve .
```
